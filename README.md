# 🍵 Matcha & Muse — Artisanal Tea & Book Parlor

> An editorial, interactive website celebrating the sensory union of single-origin Japanese teas and classic literature.

---

## 🌟 1. Project Overview & The Idea

### What is Matcha & Muse?
**Matcha & Muse** is a boutique concept website designed for an artisanal Japanese tea room and quiet indie reading parlor. It invites book lovers, tea enthusiasts, and slow-living advocates to disconnect from digital noise and experience literature through taste, aroma, and mindful pause.

### Purpose
To bridge culinary tea appreciation with literary exploration by pairing handcrafted, single-origin tea cultivars (Uji matcha, smoked Lapsang Souchong, roasted Hojicha) with curated book genres and author quotes.

### Target Audience
- Readers, writers, and students seeking a quiet, aesthetic reading sanctuary.
- Tea enthusiasts looking for direct-trade harvest notes and brewing specs.
- Anyone looking to elevate their reading rituals.

---

## ✨ 2. Key Interactive Features

1. **Interactive Tea & Reading Sommelier (Pairing Engine):**
   - Click across literary moods (*Mystery & Noir*, *Classic Literature*, *Sci-Fi*, *Poetry & Essays*, *High Fantasy*).
   - Real-time JavaScript state updates the tea blend, origin, steeping temperature, recommended book, and literary quote with smooth CSS transitions.

2. **House Signatures Carousel:**
   - Smooth, swipeable slider displaying seasonal tea and book duos.
   - Includes interactive Next/Previous controls, responsive sizing, and synchronized pagination indicator dots.

3. **Responsive Mobile Navigation:**
   - Custom hamburger menu with smooth slide-down navigation tailored for mobile screens.

4. **Interactive Nook Reservation System:**
   - Guest booking form with real-time DOM validation and dynamic confirmation card displaying the guest's name, party size, date, and welcome tea selection.

## 🛠️ 3. Technology Stack

- **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<main>`, `<section>`, `<blockquote>`, `<footer>`), accessible forms with ARIA labels.
- **CSS3:**
  - CSS Custom Properties (Design Tokens for colors, spacing, and typography).
  - Modern typography pairing: *Playfair Display* (Editorial Serif) + *Plus Jakarta Sans* (Clean Modern Sans).
  - Flexbox & CSS Grid for fluid layouts.
  - Fully responsive mobile-first design with media queries (`@media (max-width: 768px)`).
- **Vanilla JavaScript (ES6+):**
  - Event listeners, DOM manipulation, dynamic HTML templating, and CSS transition coordination.
  - Zero heavy third-party framework dependencies for lightning-fast load times.

## 🚀 4. Setup and Local Preview Instructions

### Prerequisites
All you need is any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).

### Running Locally:
1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/matcha-and-muse.git
   cd matcha-and-muse
   ```
2. **Open the website:**
   - Double-click `index.html` to open it in your default browser.
   - Alternatively, in VS Code, right-click `index.html` and select **"Open with Live Server"**.
